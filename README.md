# 🚀 MeiliSearch UI

MeiliSearch UI 是一款专为 Meilisearch 打造的现代化、功能全面且高性能的管理后台与搜索界面系统。它不仅提供了直观的索引管理和数据探索功能，还深度集成了 SaaS 多租户架构、安全网关代理以及完善的访问控制体系。

---

## ✨ 核心特性

### 🔍 卓越的搜索与探索体验
*   **即时搜索 (Instant Search)**：基于 Meilisearch 的高性能特性，提供毫秒级的搜索响应。
*   **嵌套数据查看器 (Nested Data Viewer)**：
    *   独创的深层 JSON 数据可视化展示。
    *   支持无限层级点击下钻，方便查看复杂的嵌套文档结构。
*   **高级过滤面板 (Filter Drawer)**：
    *   动态生成过滤项，支持布尔、数值范围和分类过滤。
*   **高度可定制的搜索结果表**：
    *   自定义列的显示与隐藏。
    *   拖拽调整列顺序，并持久化保存用户配置。

### 🛠️ 深度索引管理与数据导入
*   **可视化配置中心**：
    *   管理 `Searchable Attributes`、`Filterable Attributes`、`Sortable Attributes`。
    *   配置 `Stop Words`、`Synonyms` 和 `Typo Tolerance`。
*   **权重调整 (Ranking Rules)**：通过拖拽方式直观调整搜索字段的排序权重。
*   **资产管理与批量导入**：
    *   支持 **JSON 文件上传** 与 **JSON 文本输入** 两种模式。
    *   **实时数据预览**：导入前可预览解析结果，支持分页查看。
    *   **智能解析校验**：自动校验 JSON 格式并提供详细的错误反馈。
    *   **导入进度监控**：可视化展示大规模数据导入的实时进度。
*   **索引生命周期**：轻松创建（支持自定义 UID 和主键）、重命名、清空或删除索引。

### 🛡️ 企业级安全与访问控制
*   **代理网关 (Proxy Gateway)**：
    *   所有客户端请求经由 Go 后端代理，隐藏真实的 Meilisearch 地址和 Master Key。
    *   实现请求限流、黑白名单和详细的日志审计。
*   **Token 申请与审批流**：
    *   面向外部用户的 Token 申请页面。
    *   集成 163 邮箱验证码校验，防止恶意申请。
    *   管理员后台一键审批/拒绝，自动生成并分发受限权限的凭证。

### 🏢 基础多租户支持
*   **访问权限隔离**：支持针对索引(Index)级别的可见性控制与上锁功能。
*   **Token 凭证系统**：支持发放限时、限索引范围的 App-Token，确保数据访问的最小化授权。

### 📊 任务监控 (Task Management)
*   **实时任务流水线**：实时监控 Meilisearch 的异步任务（如文档更新、索引创建）。
*   **任务控制**：支持对正在运行或排队中的任务进行取消或强制终止。
*   **性能分析**：提供任务耗时的精准展示，帮助优化索引效率。

### 📱 全平台适配
*   **极致响应式设计**：完美适配手机、平板及桌面设备。
*   **暗黑模式支持**：提供舒适的视觉体验。

## 🔀 多实例聚合 (Multi-Instance)

系统支持在后台配置**多个 Meilisearch 实例**，并让前台对多个实例的数据做统一搜索与管理。

### 核心概念

| 概念 | 说明 |
| --- | --- |
| **实例 (Instance)** | 一个 Meilisearch 节点（地址 + Master Key）。 |
| **应用 (Application)** | 一个前台单元，绑定**一个主实例**，拥有独立的 `App-Key`。 |
| **聚合实例** | 应用除主实例外，额外参与聚合搜索的实例列表。 |
| **广播写入** | 对同名索引的写操作同步到所有拥有该索引的实例。 |

### 配置步骤

1. **节点管理**：添加全部 Meilisearch 实例。
2. **应用设置**：在目标应用卡片上
   - 勾选「**聚合搜索实例**」→ 前台搜索会合并这些实例的结果；
   - 勾选「**写操作多实例广播**」→ 写操作同步到所有拥有该索引的实例。
3. **前台访问**：通过 `?appKey=<应用AppKey>` 指定使用哪个应用（不传则使用默认前台 `default-app-key`）。
   例如：`https://your-host/?appKey=xxx`

### 行为矩阵

| 请求 | 未开启聚合 | 开启聚合 |
| --- | --- | --- |
| `POST /indexes/{uid}/search` | 单实例 | **多实例扇出合并去重** |
| `POST /multi-search` | 单实例 | **每个子查询分别扇出合并** |
| 索引设置 / 文档 / 统计 / 任务（读） | 主实例 | **路由到实际拥有该索引的实例** |
| 写操作（导入/更新/删除文档、改设置、删索引） | 主实例 | 开启广播则**同步到所有拥有者**，否则路由到首个拥有者 |
| 前台可见索引列表 | 主实例 | **跨实例合并去重** |
| 存储用量统计 | 主实例 | **全实例累加** |

### 指定导入目标实例

「批量新增」页面顶部提供「**目标实例**」下拉：

- **自动（默认）**：按上面的规则决定（索引归属 / 广播开关）。
- **指定实例**：本次的「创建索引」与「批量新增」直接写入所选实例。

实现上通过请求头 `X-Target-Instance: <实例ID>` 传递，后端会校验该实例是否属于当前应用可访问的集合（防止越权），并在转发给 Meilisearch 前剔除该头。

### 合并规则

- **去重**：按索引主键去重（主键自动探测并缓存，取不到时回退到 `id` 字段）。
- **排序**：结果带 `_rankingScore` 时按分数降序；否则按来源**轮询交错**，保留各实例内部相关度顺序。
- **分页**：每个实例取 `offset + limit` 条，合并去重后统一切片。
- **facets**：各实例 `facetDistribution` 按值累加。
- **统计**：`estimatedTotalHits` 为各实例之和（去重后可能略高于实际），`processingTimeMs` 取最大值。

### 注意事项

- **索引归属探测**有 60 秒缓存；新建索引后首次管理请求可能多一次探测延迟。
- **写广播**会并发写入所有拥有该索引的实例；若各实例数据本应不同源，请谨慎开启，避免数据重复。
- 广播写入仅对管理员生效（非管理员受只读模式限制）。
- 单个索引只存在于一个实例时，读/写都自动路由到该实例，无需额外配置。

## 📧 邮件配置 (SMTP)

用于发送 Token 申请验证码与审批通知，支持两种配置方式，**后台配置优先**：

1. **后台配置（推荐）**：登录后台 →「邮件配置」，填写 SMTP 服务器、端口、账号、授权码、加密方式（`SSL/隐式TLS`、`STARTTLS`、`无加密`），可一键发送测试邮件。
2. **环境变量（回退）**：`SMTP_USER` / `SMTP_PASS`（默认按 163 的 `smtp.163.com:465 SSL` 发送）。

> 后台保存后即写入数据库（`settings` 配置以单行存储），无需重启。

## 🧩 系统设置

后台「系统设置」页集中管理以下全局配置（保存在数据库中，实时生效）：

| 分组 | 配置项 |
| --- | --- |
| 品牌与文案 | 系统标题、前台默认标题、前台副标题、页脚版权 |
| Token 与申请 | Token 默认有效期(天)、申请频率限制(天)、验证码有效期(分钟)、新申请管理员通知邮箱 |
| 前台分页 | 默认每页条数、最大每页条数 |
| 申请开关 | 是否开放自助申请 Token（关闭后前台隐藏申请入口且后端拒绝） |
